# FUNCIONES PARA NOTIFY

## 1) - FUNCION PARA NOTIFICACIONES REALIZAS CON EXITO

```
Notify(
    "Request saved successfully";
    NotificationType.Success
);;
```

* Primero: definimos el mensaje que vamos a mostrar

* Segundo: Definimos el tipo de notificación, ya que según el tipo nos aparece el mensaje de un color u otro. En este caso en verde

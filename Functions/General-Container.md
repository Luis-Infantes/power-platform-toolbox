# CONCEPTOS Y FUNCIONES PARA CONTENEDORES EN POWER APPS

## FILLPORTIONS

1) Cuando queramos editar libremente un contenedor que esta dentro de otro contenedor padre, este hijo deberemos de poner la propiedad de "FillPortions = 0"

--------------------------------------------- 

## DISEÑAR Y CREAR UN MENÚ DE BOTONES DE MANERA HORIZONTAL

1) Para crear un menú de botones de manera horizontal con contenedores, debemos crear un contenedor "vertical" y dentro otro "horizontal", donde iremos añadiendo los botones que queramos.
